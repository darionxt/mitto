- A Page, whose API stays private, keeps the status, URL, header lines and body of an opaque `Response` behind it, and the Cache API stores them, as in Chrome, where an opaque entry held nothing. `navigator.storage.estimate()` counts such an entry with Chrome's padding, which hides its size from the page, and `Cache.put()` of an opaque `Response` reads its body: `bodyUsed` is then true, and a second put fails. A response that `fetch()` got comes back from a cache with every value of a line that came twice, where only the first came back ([runtime.md](docs/runtime.md#the-cache-api)).
