- A Page, whose API stays private, refuses a subresource whose URL has a user or a password, such as an `img`'s or a worker's `importScripts()`, as Chrome does, where it asked for it, unless they are those of the document's own URL and it is of the document's origin. A request in mode `cors`, such as a module's, goes without them, and a redirect to such a URL fails the request, a `fetch()`'s too. A worker's Performance Timeline has entries of `importScripts()`, where it had none, and `location.href` leaves out the user and the password of the document's URL.
