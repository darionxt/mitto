- A Page, whose API stays private, fails a put whose keys pass 127 MiB at once, as Chrome does, where its error came from a task of its own. Unless the transaction is dispatching another result, the request is done when `put()` returns, a handler set on it afterwards hears nothing, and the transaction is no longer active, so another `put()` in the same task throws `TransactionInactiveError` ([runtime.md](docs/runtime.md#indexeddb)).
