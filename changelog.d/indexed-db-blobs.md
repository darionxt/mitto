- A Page, whose API stays private, keeps the bytes of each blob and file of a value in IndexedDB, as Chrome does, where a Known Gap kept none of them and they read back empty. They read back whole, with their type, size, name and time: in the transaction that put them, before it commits, and once it has, in every Page of the Session and from its storage directory. A blob or file that a read gave stays readable after its record or its database has gone ([runtime.md](docs/runtime.md#indexeddb)).
