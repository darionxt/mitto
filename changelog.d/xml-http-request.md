- A Page, whose API stays private, has `XMLHttpRequest` as Chrome does, where it was a Known Gap that did nothing: asynchronous and synchronous requests of the kind `xhr`, in a window and in a dedicated worker, with Chrome's events, errors and timeouts, upload progress, `responseType`, `responseXML` and each kind of body ([runtime.md](docs/runtime.md#xmlhttprequest)). A `fetch()` of another origin whose `Access-Control-Expose-Headers` is no list of names exposes none of them, where it exposed the names in it.
