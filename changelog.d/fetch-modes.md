- A Page, whose API stays private, takes `RequestInit`'s `cache`, `redirect` and `integrity` as Chrome does, where a value other than the default threw: the cache mode goes to the Session as Chrome's load flags, so `reload` and `no-store` send `Pragma: no-cache` and `Cache-Control: no-cache` and `no-cache` sends `Cache-Control: max-age=0`, a redirect mode of `error` or `manual` stops at the first redirect with a network error or an `opaqueredirect` response, and integrity metadata checks the whole body before the fetch settles. A window's fetch of the default cache mode with an `If-*` line sends `Cache-Control: max-age=0`, as Chrome's does, and a `no-cors` `Request` drops a body's type that is not CORS-safelisted, such as a Blob's of `application/json`, which it kept ([runtime.md](docs/runtime.md#fetch)).
